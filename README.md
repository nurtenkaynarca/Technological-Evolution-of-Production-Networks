# Technological Evolution of Production Networks

MATLAB code for the simulations, figures and tables of

> Kaynarca, N. and Mandel, A. *Technological evolution of production networks*. Manuscript under review.

The model is an agent-based production network formation model grounded in a general equilibrium economy. In each period, one new firm attempts to enter: it targets a category of firms with similar inputs, builds on the category's essential inputs, and searches for additional inputs within the category (Scenario A, local search), or also from any firm (Scenario B, broad search) or from recently entered firms (Scenario C, recent search). Categories are derived endogenously from the production network by a clustering algorithm.

## Contents

| File | Description |
|---|---|
| `generateSimulationFiles.m` | Simulates one run of the model and saves the results to a `.mat` file |
| `i_data_ar.mat` | Initial (baseline) production network |
| `figures_main.m` | Figures and tables of the main text and of Appendices A and B |
| `appendix_C/` | Code and initial networks for the sensitivity analyses (Appendix C); see `appendix_C/README.md` |

## Requirements

- MATLAB R2020a or later
- Statistics and Machine Learning Toolbox (`corr`, `partialcorr`, `ecdf`, `tinv`)
- Parallel Computing Toolbox (optional, only to run the simulations with `parfor`)

## Reproducing the results

All simulation files, `i_data_ar.mat` and `figures_main.m` must be in the same folder.

**1. Run the simulations** (100 runs for each scenario):

```matlab
% Increasing number of categories (INC): random (0), productivity-based (1) and
% homogeneity-based (2) targeting; Scenarios A (0), B (1) and C (2)
for tg = 0:2
    for s = 0:2
        parfor k = 1:100
            generateSimulationFiles(k, tg, s, 1, 1, Inf, 0.004, 50, 0, 1)
        end
    end
end

% Fixed number of categories (FNC), random targeting
for s = 0:2
    parfor k = 1:100
        generateSimulationFiles(k, 0, s, 1, 1, Inf, 0.004, 50, 0, 0)
    end
end
```

This writes `sim_<targeting>_<scenario>_<run>.mat` (INC) and `sim_fnc_0_<scenario>_<run>.mat` (FNC).

**2. Produce the figures and tables:**

```matlab
figures_main
```

Figures are written to `graphs/` and LaTeX tables to `tables/`:

| Paper | Output |
|---|---|
| Figures 1–8 | `graphs/fig1.pdf` … `graphs/fig8.pdf` |
| Figure A1 | `graphs/figA1.pdf` |
| Figures B1–B2 | `graphs/figB1.pdf`, `graphs/figB2.pdf` |
| Table 2 | `tables/tab_exits.tex` |
| Table 3 | `tables/tab_newprod.tex` |
| Table A1 | `tables/tab_ess_only.tex` |
| Tables A2–A4 | `tables/tab_corr.tex`, `tables/tab_corr_chan.tex`, `tables/tab_corr_sup.tex` |
| Table B1 | `tables/tab_cat_growth.tex` |

Table 1 (parameter values) is part of the manuscript and is not generated by the code.

## Inputs of `generateSimulationFiles`

```matlab
generateSimulationFiles(t_s, index_targeting, index_innovation, lambda_0, lambda_0_new, ...
                        T_mature, lambda_1, ncp, index_save, index_nc, index_init)
```

| Input | Meaning | Baseline |
|---|---|---|
| `t_s` | Run number | 1–100 |
| `index_targeting` | Choice of the target category: 0 random, 1 productivity-based, 2 homogeneity-based | 0, 1, 2 |
| `index_innovation` | Search scenario: 0 local (A), 1 broad (B), 2 recent (C) | 0, 1, 2 |
| `lambda_0` | Productivity constant of incumbents ($\lambda_0$) | 1 |
| `lambda_0_new` | Productivity constant of new firms ($\lambda_0^e$) | 1 |
| `T_mature` | Periods after which new firms receive `lambda_0` | `Inf` |
| `lambda_1` | Strength of technological spillovers ($\lambda_1$) | 0.004 |
| `ncp` | Periods between two re-categorizations | 50 |
| `index_save` | 1 = also save the weight matrices (larger files) | 0 |
| `index_nc` | 1 = increasing number of categories (INC), 0 = fixed (FNC) | 1 or 0 |
| `index_init` | Initial network: 0 baseline, 1 heterogeneous sizes, 2 heterogeneous homogeneity (optional) | 0 |

Each run simulates 750 periods. The saved variables are documented at the beginning of `generateSimulationFiles.m`.
